# CABELLO | Cocinas & Interiores · V11

Web estática completa con 8 páginas, diseñada para GitHub Pages. Identidad Dark Editorial, tipografía blanca, negro piedra y acento #72CBC6. Fotografías auténticas de trabajos realizados por Nemihas Cabello.

## Cómo revisar la maqueta

Abre `index.html` en un navegador y utiliza la navegación para visitar todas las páginas. Para probarla en servidor local: `python -m http.server 8000` desde esta carpeta; luego abre `http://localhost:8000`.

## Cómo publicar en GitHub Pages

Sube **el contenido de esta carpeta**, no la carpeta contenedora, a la raíz de la rama `main` de tu repositorio de GitHub. Mantén Pages desde `main / (root)`. El fichero `CNAME` contiene `cabellointeriorismo.com`.

## Contenido y limitaciones

- Las 30 fotografías de `assets/trabajos` corresponden a obras de Nemihas Cabello, según confirmación del propietario. Se utilizaron versiones WebP optimizadas con retoques fotográficos suaves, sin cambiar materiales ni mobiliario.
- No se incluyen imágenes generadas por IA en ninguna página ni en CSS.
- Las cabeceras de escritorio, tablet y móvil son independientes. Solo se muestra la cabecera del dispositivo; no se duplican títulos H1.
- La galería permite filtrar y ampliar las fotos.
- El formulario es demostrativo: permite copiar la consulta al portapapeles, pero NO la envía ni recoge datos.
- No se han inventado teléfonos, correos ni direcciones.
- El logotipo tipográfico es provisional hasta aprobación.
